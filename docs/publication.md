# Publication, software citation and reproducibility

## Preprint

**Oka, G. U., Adan, C., Calomeno, C. V. A. Q. & de Souza, R. F. (2026).** *ppigFinder: an integrated desktop application for bacterial genome annotation and AlphaFold 3-based protein–protein interaction screening.* bioRxiv. DOI: [10.64898/2026.08.23.746524](https://doi.org/10.64898/2026.08.23.746524).

The preprint describes a *Xanthomonas citri* pv. citri strain 306 case study with a VirD4-centered candidate screen. It reports 4,303 predicted chromosomal ORFs and an XVIPCD-associated rank enrichment under the reported PAE_min criterion. Treat the study's quantitative statements as **results of that study**, not generic software defaults.

## Software citation

Use the GitHub repository's [CITATION.cff](https://github.com/leepusp/ppigFinder-v1/blob/main/CITATION.cff) when citing the software distribution itself. The preprint author list and software CFF metadata are not necessarily identical; cite the appropriate source for the intended purpose.

## Reproducible analyses

Archive input sequence accession and hashes, ORF-calling versions/parameters, homology profile/database versions, PPI candidate selection rules, JSON dialect and runner version, model seeds, reference protein lengths, confidence scoring definitions and any postprocessing scripts.

For structural models, distinguish **predicted confidence** from validated physical interaction and preserve independent evidence and controls.
