# Getting Started with ppigFinder

## Open the installed app

Open the ppigFinder shortcut or use the launcher from your installation folder.
See the [installation guide](installation.md) for operating-system-specific commands.

1. Open a genome or restore a saved [project](data_project.md).
2. Predict ORFs and inspect the genome map.
3. Annotate and select candidates for interaction analysis.
4. Export prediction inputs or configure a [local or HPC execution environment](hpc_submission.md).

Follow the [analysis workflow](../workflows/analysis_workflow.md) for the full sequence.
